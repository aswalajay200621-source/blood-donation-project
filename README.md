A clean, modern, dark-themed single-page personal portfolio website for **Aswal S Ajay**, 2nd-year B.Tech Computer Science & Engineering student at Muthoot Institute of Technology & Science (MITS), Kochi.

## 🚀 Running Locally

No dependencies or build tools required. Simply clone the repository and open `index.html` in any modern web browser, or run a local web server:

```bash
# Clone repository
git clone https://github.com/aswalajay200621-source/portfolio.git

# Navigate to project directory
cd portfolio

# Start a local HTTP server
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).
